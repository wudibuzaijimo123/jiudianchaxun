# 附近住哪儿 (Nearby Stay Radar)

一款响应式手机端 Web App / PWA 周边酒店住宿查询与多源比价工具。支持输入任意目标地点、高校校区、商圈或使用当前定位，快速扫描周边酒店、宾馆与民宿的位置距离、电话、实时空房状态，并结合 **AI 联网搜价** 将房价与主力房型直接展示在列表卡片和交互式地图气泡上。

## 核心特性

- **多引擎周边检索**：
  - **高德地图 POI 2.0 (`v5/place/around`)**：精准覆盖全国商圈及郊区/高校周边的连锁酒店、本地宾馆、民宿公寓、距离与前台电话（内置 WGS-84 ↔ GCJ-02 火星坐标纠偏，国内街道零偏移）。
  - **实时空房与分销比价 (`SerpApi Google Hotels`)**：支持按入住/离店日期实时核查空房状态与多渠道（Trip.com/携程、Agoda、Booking 等）人民币报价。
  - **AI 全网搜价与国内情报提纯（借鉴 TripStar 架构）**：结合国内携程/同程/美团/抖音/小红书公开检索摘要，调用兼容 OpenAI 格式的大模型（如 DeepSeek、通义千问等）自动提取各门店起步价、价格区间、主力房型价目表、抖音团购参考价及住客避坑提示，直接打印在列表卡片与地图打点气泡上。
- **双视图联动 + 多维筛选**：
  - 电脑端左右分屏联动，手机端支持一键切换「列表浏览 / 地图打点」，支持拖动地图「搜索当前视野中心周边酒店」。
  - 支持搜索半径（`500m` ~ `5km`）、预算区间、酒店类型、品牌关键词过滤以及按距离/低价/高分排序。
- **跨端 PWA 与局域网扫码同步**：
  - 支持添加到 iOS（Safari 添加到主屏幕）和 Android / 桌面端独立全屏运行；支持同一 Wi-Fi 手机扫码一键同步体验。
  - 本地持久化保存「收藏备选酒店」与「历史搜索足迹」。

## 快速开始

### 环境要求
- Node.js >= 18

### 安装与启动

```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务
npm run dev
```

Windows 环境下也可直接双击根目录 `启动酒店查询服务.bat` 一键启动并自动打开浏览器 `http://localhost:5173`。

## 接口密钥配置（纯本地存储，零硬编码）

所有 API Key 均由使用者在页面右上角 **「配置接口Key」** 弹窗中自行填写，**仅保存在当前浏览器的 `localStorage` 中**，仓库源码中不包含任何私钥或凭证：

1. **高德开放平台 Key**：前往 [高德开放平台控制台](https://console.amap.com/dev/key/app) 创建应用并添加 **「Web服务」** 类型的 Key。
2. **SerpApi Key（可选）**：前往 [SerpApi](https://serpapi.com/manage-api-key) 注册免费个人计划获取 `Private API Key`，开启实时空房与国内公开网页检索。
3. **AI 大模型 Key（可选）**：支持任意兼容 OpenAI 接口规范的模型服务（如 DeepSeek `https://api.deepseek.com/v1`、通义千问等），开启全表自动搜价与房型价目表智能提纯。
